# Target classification

- Site: `https://books.toscrape.com/`
- Why: this is a public practice catalog site meant for scraping exercises and contains predictable listing pages.
- How much: the first 3 catalogue pages only.
- Data collected: book title, price, availability, rating, and product page URL from each listing on those pages.
- Why this is appropriate: the scope is limited to public catalog metadata and avoids collecting anything personal or sensitive.
